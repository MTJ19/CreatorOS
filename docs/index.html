System Design

6-Layer Modular Architecture

Engineered with strict separation of concerns to guarantee auditability, legal safety, and performance.

Supabase PostgreSQL & Immutable Audit Log

The foundation of CreatorOS stores creators, brands, deals, contracts, and deliverable state with Row Level Security (RLS).

  • Row Level Security ensuring tenant and creator data isolation
  • S3-compatible Object Storage for contracts and media drafts
  • Append-only activity log for end-to-end deal traceability
// Immutable Shared Activity Log Schema CREATE TABLE activity_log ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), deal_id UUID REFERENCES deals(id), actor_role TEXT CHECK (actor_role IN ('agency', 'creator', 'brand')), action_type TEXT NOT NULL, payload JSONB NOT NULL, created_at TIMESTAMPTZ DEFAULT NOW() );

Deterministic Rate & Rule Engine

Financial and compliance evaluations run on deterministic mathematical formulas and pattern matchers to ensure zero hallucination risk.

  • CPM-based rate range formulation with engagement multipliers
  • Compounding weekly growth confidence forecasting
  • Pre-send checklist compliance gate enforcing critical deal terms
// Deterministic Rate Calculation export function computeAskRange(views: number, cpm: number, tierBonus: number, eng: number) { const base = (views / 1000) * cpm + tierBonus; const modifier = 1 + (eng - 3.0) * 0.05; const target = Math.round(base * modifier); return { floor: Math.round(target * 0.85), target: target, ceiling: Math.round(target * 1.35) }; }

AI Contract Screening & Content Health

Targeted LLM reasoning passes analyze legal agreements and score pre-publish video drafts without risking financial inaccuracies.

  • Red-Flag Detection (Perpetual rights, unlimited revisions, unpaid boosting)
  • Plain-language clause summaries for non-legal creators
  • Multi-Agent Content Health Score (Niche, Cold Viewer, Platform Benchmark)
// Multi-Agent Content Health Evaluation const [nicheReview, coldReview, patternReview] = await Promise.all([ nicheAgent.evaluate(scriptContent), coldViewerAgent.evaluate(scriptContent), platformPatternAgent.evaluate(scriptContent) ]); const synthesis = await orchestrator.synthesize([ nicheReview, coldReview, patternReview ]);

Finite State Machine & E-Sign Locks

Orchestrates deal lifecycle transitions and enforces hard compliance gates before legal execution.

  • Automatic e-sign locking whenever high-risk clauses are triggered
  • Compliance queue escalation to legal lead or agency admin
  • State synchronization across WhatsApp, email, and web portals
// Deal Lifecycle State Transitions type DealState = | 'INTAKE' | 'RATE_CALCULATED' | 'NEGOTIATION_DRAFTED' | 'CONTRACT_UPLOADED' | 'LEGAL_ESCALATION_LOCKED' | 'E_SIGN_READY' | 'DELIVERABLE_SUBMITTED' | 'BRAND_APPROVED' | 'PAYMENT_SETTLED';

Multi-Portal Role-Based Presentation

Tailored React interfaces designed for distinct stakeholder personas sharing a single audit trail.

  • Agency Portal: Pipeline management & compliance queue
  • Creator Portal: Rate calculator, negotiation scripts & deliverables
  • Brand Portal: Zero-login magic-link review & approval interface
